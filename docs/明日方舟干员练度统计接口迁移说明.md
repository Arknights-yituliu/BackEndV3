# 明日方舟干员练度统计接口迁移说明

## 一、迁移概况

干员练度统计（干员养成数据分布统计）能力已从本后台（BackEndV3）迁出，现由用户中心（UserCenterV1）统一提供。

- 旧接口已于 2026-10-24 下线，本后台不再提供该统计查询能力，也不再执行统计跑批任务。
- 新接口地址与完整字段说明见用户中心文档：
  https://github.com/Arknights-yituliu/UserCenterV1/blob/dev/docs/open/%E5%B9%B2%E5%91%98%E6%95%B0%E6%8D%AE%E7%BB%9F%E8%AE%A1%E6%8E%A5%E5%8F%A3%E6%96%87%E6%A1%A3.md

## 二、旧接口（已废弃）

| 项目 | 说明 |
| :-- | :-- |
| 接口路径 | `GET /survey/operator/result/v2` |
| 所在后台 | 本后台（BackEndV3） |
| 鉴权 | 无 |
| 返回结构 | `{ code, msg, data: { sampleSize, result: [...], recordType, createTime } }` |
| 当前状态 | 已下线，调用将返回 404 |

同时下线的手动触发统计接口：

| 接口路径 | 说明 |
| :-- | :-- |
| `GET /survey/statistic` | 手动触发一轮干员练度统计，已随统计逻辑一并移除 |

本后台用于统计的定时任务、结果表写入/读取链路均已删除，后续请勿再调用旧路径。

## 三、新接口

新接口由用户中心（UserCenterV1）提供，无需鉴权：

| 版本 | 接口路径 | 说明 |
| :-- | :-- | :-- |
| V1 | `GET /open/ak-operator-statistics/result` | 模组分布字段为 `modA` / `modX` / `modY` / `modD` / `modB` |
| V2 | `GET /open/ak-operator-statistics/v2/result` | 模组分布字段改为 `equipA` / `equipX` / `equipY` / `equipD` / `equipB`，与源表列名对齐 |

两个接口的请求方式、鉴权、响应结构和排序规则完全一致，**新接入请优先使用 V2**。

### 响应结构

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": [
    {
      "charId": "char_145_prove",
      "own": 31576,
      "sampleSize": 47993,
      "elite": { "0": 25212, "1": 3273, "2": 3091 },
      "skill1": { "0": 31377, "1": 19, "2": 14, "3": 166 },
      "skill2": { "0": 31183, "1": 63, "2": 25, "3": 305 },
      "skill3": { "0": 31576 },
      "modA": { "0": 31576 },
      "modX": { "0": 31327, "1": 128, "2": 12, "3": 109 },
      "modY": { "0": 31576 },
      "modD": { "0": 31576 },
      "modB": { "0": 31576 }
    }
  ]
}
```

- `data` 为干员数组，按 `charId` 升序排列，一次返回全部干员，不支持分页或按干员过滤。
- 分布字段固定为 `{ "<取值>": <记录数> }` 对象，无数据时为空对象 `{}`。
- 统计结果由用户中心定时离线跑批生成并落库，接口只读结果表；尚未跑过统计时返回 `code = 200`、`data = []`。

## 四、新旧结构差异与适配

1. **响应根结构变化**
   - 旧接口：`data` 是对象，包含全局 `sampleSize`、`result` 数组、`recordType`、`createTime`。
   - 新接口：`data` 直接是干员数组，`sampleSize` 改为每个干员各自的样本数；不再提供 `recordType`、`createTime`。

2. **字段变化**
   - 干员级字段 `charId`、`own`、`sampleSize`、`elite`、`skill1`、`skill2`、`skill3` 含义保持一致。
   - V2 仅把模组分布字段由 `modA` / `modX` / `modY` / `modD` / `modB` 改名为 `equipA` / `equipX` / `equipY` / `equipD` / `equipB`。
   - 分布对象仍为「取值 → 记录数」，与旧接口 `Map<Integer, Integer>` 序列化后的形态一致，消费方无需额外转换。

3. **调用地址**
   - 旧地址（本后台域名下的 `/survey/operator/result/v2`）不再可用。
   - 新地址为 UserCenterV1 域名下的 `/open/ak-operator-statistics/v2/result`。

## 五、注意事项

本后台仍保留的 `GET /open-api/operator/info` 是「读取当前用户自己的干员练度」，不属于干员练度统计接口，本次迁移不影响该接口。
